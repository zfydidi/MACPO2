\noindent\textbf{1. 查阅文献与调研}

\par
\indent
近年来，随着智能制造、智慧能源、无人系统与车联网等应用的快速发展，大规模网络化协同优化问题日益突出。全局目标与约束通过网络拓扑耦合，各节点仅掌握局部信息并依赖有限带宽通信协同决策，决策变量同时包含私有变量与共享变量，问题呈现典型的黑箱、非凸与大规模特征，对算法的自适应性与通信效率提出了更高要求。

\par
\indent
针对上述问题，本人系统查阅了网络化分布式优化（NDO）、黑箱约束处理、多智能体协同进化及强化学习赋能优化等方向文献。对传统凸分布式方法（如 ADMM、EXTRA、DGD）以及协同协进化算法（CCEA、DPSO、GFPDO、MACPO）的发展脉络进行了梳理，认识到前者依赖凸性与梯度可得等假设，难以适应高度非线性场景；后者为黑箱 NDO 提供了可扩展框架，但惩罚参数与通信策略多依赖人工经验或静态规则，难以反映约束冲突与演化阶段的动态变化。

\par
\indent
经文献调研归纳，现有研究主要存在以下不足：一是惩罚强度难以随协商冲突动态调整，固定规则在不同优化阶段适应性不足；二是共享变量协商缺乏针对性筛选，通信负载偏高；三是通信触发策略缺少与冲突态势相协调的门控机制，协同开销与优化质量难以兼顾。结合开题阶段形成的文献综述，本人明确了“轻量级 RL 自适应惩罚调控 + 冲突门控通信 + 变量重要性筛选”的技术路线，并参加 ACM 图灵大会、ChineseCSCW、CCF 演化计算学术会议等活动，持续关注领域进展，为后续算法设计奠定理论基础。

\noindent\textbf{2. 工作进度}

\par
\indent
针对网络化分布式优化中共享变量协同效率低、约束冲突处理依赖人工经验以及通信开销较大的问题，本课题以 MACPO 算法为基础，围绕“强化学习自适应惩罚调控”和“智能通信协商”两个方面开展研究，希望通过强化学习动态调整惩罚强度，并结合共享变量重要性分析减少无效通信，在保证优化质量的同时降低通信成本。

\par
\indent
在此基础上，本文提出 RL-MACPO 算法，总体创新主要包括以下三个方面：

\par
\indent
（1）\textbf{轻量级强化学习自适应惩罚调控。}针对固定惩罚难以适应冲突演化的问题，以全局冲突指标 CI 与变化趋势 $\Delta$CI 构成二维状态，采用轻量策略网络在线调节惩罚比例因子，使惩罚强度能够随协商态势动态变化，从而缓解“前期过弱、后期过强”等阶段性失配。

\par
\indent
（2）\textbf{基于 EMA 与 Top-$k$ 的共享变量筛选。}针对共享维度“全量协商”带来的通信冗余，对各共享变量冲突强度进行指数滑动平均累积，按重要性评分选取 Top-$k$ 变量参与协商，从空间维度压缩单次通信数据量，使有限带宽更多用于真正影响全局一致性的关键维度。

\par
\indent
（3）\textbf{三层门控通信控制机制。}针对每轮固定通信开销偏高的问题，设计最小通信间隔、相对冲突阈值判断与阶段感知概率采样三层门控，从时间维度动态决定是否触发邻居协商，在冲突不明显时主动抑制冗余通信，在冲突加剧时及时恢复协同。

\par
\indent
目前已完成 RL-MACPO 核心算法设计、C++/MPI 程序实现及 Windows+WSL 多机并行实验环境搭建，建立统一实验日志与通信统计模块，具备标准基准与基线算法批量复现能力，并进入实验完善与论文撰写阶段。具体实验进展见续页。

\noindent\textbf{3. 实验}

\par
\indent
\textbf{3.1 实验目的与设置。}为验证所提方法的有效性，首先在 MACPO 原文采用的 CEC2013 LSGO 基准函数 F1--F6 上开展对比实验。该组算例覆盖可分、部分可分及高度耦合等不同类型的大规模黑箱优化问题，能够较全面评价算法在不同约束冲突程度下的优化性能与稳定性。主实验沿用 20 智能体链式网络设置，嵌入优化器以 LLSO 为主、CSO 为对照；各函数独立重复多次运行，统一评价预算与随机种子，并采用 Wilcoxon 符号秩检验评估显著性。扩展实验进一步覆盖 F7--F18 更高维度算例，通信效率实验统计外循环中触发邻居协商的比例，应用验证选取多区域电力经济调度、资源受限调度与电动汽车充电协调等网络化调度场景。

\par
\indent
\textbf{3.2 F1--F6 主对比实验。}为验证所提出算法在典型大规模黑箱场景下的整体优化能力，首先在 MACPO 原文采用的 CEC2013 LSGO 基准函数 F1--F6 上开展主对比实验。该组测试函数覆盖可分、部分可分以及高度耦合等不同类型问题，能够较全面评价算法在不同约束冲突程度下的寻优性能。实验沿用 20 智能体链式网络，嵌入优化器以 LLSO 为主、CSO 为对照，各函数独立重复运行并采用 Wilcoxon 符号秩检验评估显著性。实验结果表明，在 LLSO 优化器下，RL-MACPO 在六个测试函数上均获得优于 MACPO 的最终优化结果，且检验均达到统计显著水平；其中，在共享变量冲突较为明显的 Rosenbrock 类测试函数（F3--F5）中，改进算法优势更加突出，说明强化学习能够根据当前优化状态动态调整惩罚强度，有效缓解固定惩罚策略在不同优化阶段适应性不足的问题。CSO 设置下亦取得一致优势，表明方法对不同局部搜索机制具有一定鲁棒性。综上，主对比实验从标准基准层面验证了 RL 惩罚调控与门控通信协同设计的有效性。

\par
\indent
\textbf{3.3 消融实验与 RL 结构对比。}主对比实验虽能说明整体有效性，但尚不足以解释“性能提升究竟来自哪一模块”。为此，围绕门控深度、阶段采样策略及 RL 结构复杂度等开展消融与对比实验，以检验各设计是否必要、是否冗余。实验结果表明，完全取消门控会导致结果波动增大、性能明显退化；引入相对冲突阈值门控是恢复性能与稳定性的关键环节；阶段感知采样在此基础上带来进一步边际改善。与 DQN、A2C、PPO 等较重 RL 结构对比表明，在当前问题规模下轻量级线性策略已能满足惩罚调节需求，兼顾效果与实现开销。进一步地，“仅 RL 惩罚、无门控通信”等配置表现欠佳，说明惩罚自适应与通信门控需要协同设计，而非简单叠加。上述分析为后续论文撰写中的机制论证提供了依据。

\par
\indent
\textbf{3.4 F7--F18 扩展实验。}F1--F6 主实验主要反映方法在标准链式网络上的基础性能，但学位论文还需回答“规模扩大后机制是否仍然有效”。考虑到实际应用往往面临更高维决策空间与更复杂网络拓扑，在 F7--F18 扩展算例上进一步检验可扩展性。实验显示，随问题规模增大，RL-MACPO 在多数算例上仍保持更优的最终精度与更平稳的收敛过程，未出现“小规模有效、大规模失效”的明显退化。这说明所提惩罚调控与门控通信机制并非仅适用于低维试点算例，而具备向更大规模 NDO 问题推广的潜力，为后续面向工程场景的验证奠定了基础。

\par
\indent
\textbf{3.5 通信效率分析。}优化精度提升固然重要，但若通信开销过高，方法仍难以部署于带宽受限的网络化系统。为进一步验证门控通信策略是否能够真正减少协同开销，在保证优化精度基本不变的前提下，对算法运行过程中触发邻居协商的次数进行了统计分析。结果表明，MACPO 采用每轮固定协商策略，通信始终处于较高频触发状态；RL-MACPO 通过冲突门控与变量筛选，使有效通信比例大幅下降，在 F1--F12 及电力调度、资源受限调度、电动汽车充电协调等应用案例中均观察到明显的通信次数减少，且最终解质量保持或优于基线。结果说明，所提通信机制并非以牺牲优化质量换取通信节省，而是在冲突态势允许时主动抑制冗余协商，使有限通信资源更多用于“确有必要的协同时刻”，更符合网络化系统对带宽与实时性的实际需求。F13--F18 通信统计正在多机环境下补充完善。

\par
\indent
\textbf{3.6 基线算法复现。}为增强结论说服力，按 MACPO 论文实验协议复现 DPSO、GFPDO 等代表性协同进化基线。DPSO 在 F1--F6 上的重复实验已完成；GFPDO 复现正在多机并行环境下补充，用于完善与领域内主流方法的横向比较。
