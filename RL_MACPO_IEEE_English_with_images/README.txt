这个压缩包是按 LatexSample 的 IEEE conference 样式整理的中文模板工程。

包含：
1. conference_cn_ready.tex：中文可用的 IEEE 会议模板主文件
2. IEEEtran.cls：样式文件
3. fig1.png：图片引用示例
4. conference_101719.pdf：原模板 PDF 参考

说明：
- 你的本地 Cursor 文件 `初稿.tex` 我已经按这个方向做了结构改造。
- 如果你要继续把整篇正文彻底替换成该模板下的最终可编译版，最稳的方式是基于这个模板工程继续清洗正文。
- 图片目录已按示例风格设置：图片和 tex 同目录，直接 \includegraphics{xxx.png}。
